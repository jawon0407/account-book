# Core BFF 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 로그인한 PC 브라우저가 기존 Nest 프로필·계좌·카테고리 API를 서버 전용 인증 경계로 이용한다.

**Architecture:** 고정 route → CoreController → 기존 SessionService + DelegatedApiClient → Nest API. 입력/응답 경계를 작은 파일로 분리하며 DB·AuthController는 확장하지 않는다.

**Tech Stack:** TypeScript, Next 16 Node route handlers, Zod 공유 계약, Vitest, 기존 Nest API.

## 작업 전제

- 기존 worktree `ledger-public-contracts`, `feature/bank-state-transitions`를 재사용한다. 기존 미커밋 코드는 보존한다.
- DB 테이블 생성은 실제 확인 완료. 원격 migration/쓰기/권한 변경 없음.
- 사용자 지시로 반복 승인 단계는 생략하되 문서 → RED → 구현 → GREEN → 검토 순서를 지킨다.
- 약 20개 파일. 새 의존성 없음. 소스/테스트 약 800~1,200행 예상(검증 항목에 따라 변동).
