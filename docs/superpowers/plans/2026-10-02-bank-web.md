# A4 Bank Web Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 은행 연결 API를 안전한 BFF와 PC 시작·결과 화면에 연결한다.
**Architecture:** Next Node BFF는 세션·CSRF·proof, Nest는 은행 code/token을 소유한다.
**Tech Stack:** TypeScript, Next, ky, React Query, Vitest, Playwright.
**Spec:** `docs/superpowers/specs/2026-10-02-bank-web-design.md`

## Global Constraints

현재 feature/bank-state-transitions 작업트리 유지. 사용자 main 변경 보존. 신규 의존성/DB 변경/실제 은행 호출 없음. 모든 신규 함수의 역할·매개변수 한국어 주석. 작업 시작 전 파일과 규모 고지 완료. commit/push는 검증 후 해당 feature 브랜치만 사용한다.
