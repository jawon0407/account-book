# Android 착수 전 인증 감사 보완

## 범위와 원칙

Android 우선, iOS는 Android 구현·검증 이후로 유지한다. 이번 단위는 기존 공통 인증 경계의 보완이며 Android 앱·알림 수집기 구현 완료가 아니다. 기존 원장/은행 A5 작업은 보존한다. 외부 DB 적용, 실제 사용자 계정 조작, PR 병합은 포함하지 않는다.

착수 예상은 약 11개 파일이었다. 실제 영향은 인증 구현 1개, 인증 테스트 4개, 브라우저 테스트 1개, 의존성/잠금/정책 4개와 문서 3개로 총 13개 파일이다. 전체 파일 재작성이나 DB 변경은 하지 않는다. 기존 원장/은행 단위 변경과 구분한다.

## 발견 사항

- 로그아웃은 요청 출처·CSRF 검증에 실패해도 세션 쿠키 삭제 헤더를 반환했다. 서버 세션 탈취는 아니지만 원하지 않는 브라우저 로그아웃을 유발할 수 있다. 검증 실패 응답은 쿠키를 변경하지 않아야 한다.
- 인증 커버리지는 1037개 테스트가 통과해도 분기 836/839(99.64%)여서 기존 100% 게이트에 미달했다. 공급자 입력, 제공자 사용자 스키마, OAuth DB 행 오류의 거부 분기 3개를 추가 검증한다.
- Next 16.3.6 / source-map-js 1.2.1에 high 경고가 있었다. Next 이미지 remotePatterns가 없으므로 해당 SSRF의 현재 실행 조건은 확인되지 않았고 source-map-js는 빌드 의존 경로다. 위험의 도달 가능성과 패키지 경고를 구별하되 패치로 해결한다.
- PR #22 원격 CI 실패는 인증 분기 커버리지 단계다. 로컬 수정·검증만으로 원격 CI 성공이나 PR 전체 리뷰 완료를 주장하지 않는다.
- 운영 의존성 패치 후 개발 도구까지 감사 범위를 넓히자 undici 7.29.0(jsdom)과 brace-expansion 5.0.9(ESLint 경로)에 경고 13건(high 4 / moderate 6 / low 3)이 남았다. 두 패키지는 감사 결과 dev 경로다. undici 7.29.1, brace-expansion 5.0.12로 한정 패치하며 workspace override·lockfile·정책 테스트만 추가 수정한다. 실제 운영 서비스 침해가 확인됐다는 의미는 아니다.

## 작업 순서

- [x] 로그아웃 잘못된 출처·CSRF·쿠키·폼 요청이 쿠키/서버 세션을 변경하지 않는 회귀 테스트를 먼저 실패시킨다.
- [x] 요청 검증 이후에만 쿠키 정리를 허용한다. 정상 요청의 로컬 폐기 우선·제공자 실패 보류 동작은 유지한다.
- [x] 미검증 인증 거부 분기 3개를 테스트한다. 커버리지 대상/기준은 줄이지 않는다.
- [x] Next 16.3.8, source-map-js 1.2.2 정책 테스트를 먼저 실패시키고 manifest/override 및 생성 lockfile을 갱신한다.
- [x] 개발 도구 패치 정책 테스트를 먼저 실패시키고 undici 7.29.1 / brace-expansion 5.0.12를 반영한 뒤 전체 의존성 감사를 재실행한다.
- [x] 테스트·커버리지·타입·린트·빌드·의존성 감사를 재실행한다.
- [x] 합성 계정/폐기용 로컬 DB로 Playwright PC 인증 흐름을 검증한다. 실제 계정과 외부 DB를 사용하지 않는다.
- [x] 독립 코드 리뷰와 문서/Notion 진행 기록을 갱신하고 다음 Android 인증·단일 수집 기기 계약으로 연결한다.

## 도구 제한

autoplan 일부 필수 참고 파일과 qa-only 보고서 템플릿이 설치 경로에 없었다. 전체 파이프라인 실행 완료로 표시하지 않는다. gstack browse는 server.ts를 찾지 못해 실행되지 않았으므로 PC 브라우저 검증은 설치된 Playwright로 대체한다. 보안 스캔은 알려진 패턴 범위이지 모든 비밀/취약점이 없다는 증명이 아니다.

## 검증 기록

[상세 검증 기록과 다음 작업](../../status/2026-10-16-android-foundation-audit.ko.md)에 파일 지도, 초급 개발자용 원리, 테스트 결과·중간 실패·PC 화면·PR 경계·미검증 범위를 기록한다.

- 웹 1,058개 및 선택된 인증/보안 19파일의 분기 839/839(100%) 통과. 프로젝트 전체 커버리지 100%로 표현하지 않는다.
- 최종 `pnpm verify` 종료 0: lint·6 workspace 타입·1,746 tests(208+96+19+279+1,058+86)·API 및 Next 16.3.8 production build 통과. 중간 정책 테스트 오탐 실패는 상세 기록에 보존한다.
- 실제 폐기용 PostgreSQL 306개, core PC Playwright 15개 통과. 실제 OAuth/금융 앱·hosted DB·Android 기기 시험과 구별한다.
- 전체·운영 의존성 감사 모두 알려진 취약점 0건. 개발 도구 정책의 override 오탐은 독립 리뷰 지적 후 실제 설치 섹션만 검사하도록 수정했고 집중 5/5 및 재리뷰 통과.
- 이번에 시작한 QA용 BFF/API/합성 IdP와 폐기용 PostgreSQL은 검증 후 종료했다. 사용자 실제 로컬 앱이나 외부 DB는 변경하지 않았다.
- [Notion 07 진행 기록](https://app.notion.com/p/3e2323168ba681b59204c2342edb27b3)에 결과와 다음 단위를 반영하고 읽기 확인했다. 기존 과거 기록과 자료 링크는 보존했다. 이 체크 완료는 본 인증 보완 단위에 한정하며 Android 구현·PR 병합·배포 완료가 아니다.
