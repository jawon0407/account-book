# Android 알림 수집 설정 UI

## 범위

승인된 계정당 수집 기기 1대 정책과 [기존 HTTP 계약](2026-10-16-collector-http-design.md)을 앱에서 조작한다. 새로운 OS 권한이나 금융 알림을 읽지 않는다. 서버·DB·의존성은 변경하지 않는다. 사용자에게는 “수집 기기 지정”과 “자동 기록 준비 중”을 분리해 보여준다. 알림 원문·토큰·기기 식별자를 화면/로그/분석 이벤트에 노출하지 않는다.

## 화면과 동작

장부 메뉴의 ‘수집 설정’ → ‘알림 수집 설정’. Android 뒤로 가기와 화면의 돌아가기는 장부로 이동하며 기존 수기 초안을 보존한다.

- 미지정: 현재 지정된 기기가 없다는 안내와 ‘이 기기 지정’.
- 이 기기: 현재 로그인 세션이 지정됐다는 안내와 ‘기기 지정 해제’.
- 다른 기기: ‘이 기기로 변경’과 ‘기기 지정 해제’. 다른 기기 식별자는 표시하지 않는다.
- 변경 전 확인 영역에서 영향과 취소/확정을 제공한다. 다른 기기로부터 가져올 때만 `replaceExisting:true`; 모든 쓰기는 읽은 `expectedVersion`을 보낸다.
- 조회/변경 중 버튼 중복 실행 차단. 화면 진입과 사용자의 새로고침 때 GET. 지속 폴링 없음.
- PATCH 성공 전 성공 표시 금지. 실패하면 PATCH를 자동 재전송하지 않고 GET으로 현재 상태를 재확인한다. 실패 후 GET도 실패하면 변경 버튼을 잠그고 다시 조회만 제공한다.
- 실패 뒤 재조회가 성공해도 “요청 성공”으로 단정하지 않는다. 현재 상태만 표시하고 사용자가 다시 판단한다. 버전 충돌/교체 필요/연결 불확실성은 안전한 고정 안내로 구별한다.
- 로그아웃·foreground 재검증 때 SessionManager의 기존 세대/epoch 검사를 따른다. 화면 종료 이후 늦은 응답은 버리고 재진입 시 새 조회한다.
- 안내: “현재는 수집 기기만 지정할 수 있어요. 금융 앱·문자·카카오톡 알림을 읽거나 거래로 저장하지 않아요.” OS 권한을 받았다고 표시하지 않는다.

## 구현 경계와 시험

NativeCollectorClient는 경로/입출력 계약만, SessionManager는 토큰·계정 경계만, CollectorSettings는 로딩/확인/충돌/요청 수명만, 화면은 표시와 선택만 담당한다. React effect 재설정(start→stop→start)에서도 안전하게 재조회한다. 확인창을 닫거나 뒤로 가도 수기 초안은 유지한다.

계약 오염·재시도 0·401/계정 전환·느린 응답·연타·취소·버전 충돌·응답 유실 후 GET·GET 실패 잠금·재시작을 순수 테스트로 검증한다. 가능한 Android 실기기에서 진입/지정/해제/뒤로 가기/줄바꿈을 확인하고, PC는 Playwright로 같은 장부 조회 회귀를 확인한다. 기기가 없으면 화면 검증을 미완료로 명확히 기록하며 OS 보안을 임의 변경하지 않는다.

## Direction contract

THESIS: 사용자가 어떤 기기를 지정했는지와 아직 자동 기록되지 않는다는 사실을 한 화면에서 구분한다. 동작하지 않는 권한 스위치는 만들지 않는다.

OWN-WORLD: 기존 모바일 theme의 Bookify 파랑/회색 바탕/흰 표면과 시스템 글꼴을 그대로 사용한다. 새로운 시각 체계나 전역 토큰 변경은 없다.

STORY: 돌아가기 → 준비 상태 → 서버의 기기 지정 상태 → 영향 확인 → 명시적 저장 → 결과 재확인 순서다.

FIRST VIEWPORT: 상단 돌아가기·24sp 제목, 자동 기록 미지원 안내, 현재 지정 상태와 주요 행동. 보조 새로고침·계정당 1대 설명은 아래. 스크롤 가능, 48dp 이상 버튼과 8dp 이상 간격.

FORM: 기존 화면의 좁은 확장, Operate/code-led. 사용자 지정 Bookify 방향을 유지하며 seed/새 디자인 선택은 하지 않는다. 핵심 상호작용은 현재 상태가 확인 단계로 전환되고 확정 전 취소할 수 있는 흐름이다. 불필요한 모션은 추가하지 않는다.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
