# Android 누적 개발 체크포인트 — 2026-10-21

## 사용자 승인과 변경

로그인 안내 수정에 더해 이전 완료 작업도 함께 커밋·푸시하도록 승인받았다. 기존 `feature/bank-state-transitions` 작업 공간을 유지한다. Android 기반·이메일 인증·장부 HTTP·수기 입력·시각·단일 수집 기기 서버 계약·안전한 세션 복원과 관련 문서/시험을 함께 저장한다.

로그인 안내는 “앱을 다시 열면 로그인 상태를 안전하게 확인해요. 세션이 만료되면 다시 로그인해 주세요.”로 고쳤다. 자동 수집 기능을 구현했다는 의미는 아니다. 이전 설계서의 재실행 시 세션 정리 정책은 10/20 복원 정책으로 대체됐음을 표시했다.

## 현재 실행 근거

- `pnpm lint`, `pnpm typecheck` 성공.
- `pnpm test` 전체 2,164개 성공: 저장소 208, 계약 176, DB 모델 19, 모바일 도구 10/코어 121, API 320, 웹 1,219, E2E 사전검사 91.
- 독립 읽기 전용 리뷰: Android/인증/수집 권한/시각 범위에서 Critical/Important 없음. 전체 저장소 전수 보안 감사는 아니다.
- 커밋 후보 282개에서 env·개인키·인증서·APK·output 파일 없음. 넓은 패턴 검사에 걸린 DB 주소는 루프백의 폐기용 테스트 계정이다. 테스트용 가짜 개인키 표식은 실제 비밀값이 아니며, 키 차단 시험을 유지하면서 표식을 실행 시 조립하도록 정리했다. 저장소 보안 게이트는 별도로 적용한다.
- `query-string` 패치 파일의 공백 한 줄은 unified diff 문맥이므로 그대로 보존한다. 일반 코드의 trailing whitespace와 구분한다.

## 제외 및 남은 검증

`apps/web/next-env.d.ts`는 개발 서버가 자동 생성한 변경이므로 보존하되 커밋하지 않는다. Supabase CLI 임시 파일은 ignore에 추가했다. 운영 DB·배포·실제 금융정보·휴대폰 보안 설정은 변경하지 않는다.

10/21 실기기/PC 근거는 별도 세션 복원 기록에 있다. 이번 체크포인트에서 운영 빌드·전체 DB 통합·새 의존성 감사·원격 CI를 다시 통과했다고 주장하지 않는다. OS 재부팅·최근 앱 미리보기·저장 도중 통신 단절·실소셜·알림 읽기는 후속이다. 기존 의존성 경고의 해소 여부도 별도 확인 대상이다.
