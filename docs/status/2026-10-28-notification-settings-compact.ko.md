# 알림 설정 버튼·문구 정리

## 요청과 작업 계획

사용자가 지정한 작은 UI 수정이다. 기능·권한·동의·DB 계약은 변경하지 않는다.

1. 버튼 내부 세로 여백을 12dp에서 9dp(75%)로 줄인다. 실제 터치 영역은 48dp 이상으로 유지하고 안쪽 버튼 표면만 줄인다.
2. ‘자세히 알아보기’와 ‘알림 허용’을 같은 행의 두 열로 배치한다. 긴 글자는 줄바꿈하며 잘라내지 않는다.
3. ‘동의와 알림 접근’을 ‘알림 설정’으로 바꾼다.
4. 본문은 금융 앱·카카오톡·문자 알림을 활용하기 위해 Account Book의 알림 접근을 허용하라는 안내로 바꾼다. 현재 실제 알림 분석·저장은 미구현이라는 기존 상단/상세 안내를 유지한다.

사진의 별도 ‘이 기기 지정’ 버튼은 직전 승인 작업에서 ‘알림 허용’ 흐름에 통합됐다. 이를 다시 만들지 않고 현재 기기 지정 확인·해제 버튼에도 같은 압축 여백을 적용한다.

## 변경 파일

- `apps/mobile/src/ui/collector-screen.tsx`: 기기 지정 관련 버튼의 내부 여백/터치 영역 분리.
- `apps/mobile/src/ui/notification-access-panel.tsx`: 제목·본문·2열 버튼, 알림 허용 버튼 여백.
- `apps/mobile/src/ui/notification-access-guide.tsx`: 안내 버튼 여백과 열 너비 대응.
- 모바일 surface brief와 이 기록: 디자인 결정·검증 결과 갱신.

공용 theme, 서버/API, DB, Android 네이티브, 의존성, PC 코드는 바꾸지 않는다. 새 테스트 코드는 추가하지 않고 기존 모바일 테스트·타입 검사·lint·Android 번들·PC Playwright 회귀로 확인한다. 실제 기기가 연결되어 있지 않으면 실기기 검증 완료라고 표시하지 않는다.

## 결과

- 구현 완료: UI 3파일 +117/-63줄. 대부분은 두 버튼을 같은 행으로 옮기면서 생긴 들여쓰기 변경이며 새 기능이나 의존성은 없다. 표면 문서 1파일과 이 결과 문서까지 총 5파일이다.
- 본문: “휴대폰에 도착하는 금융 앱·카카오톡·문자 알림을 가계부에서 활용하려면 Account Book의 알림 접근을 허용해 주세요.”
- 버튼은 왼쪽 안내/오른쪽 허용, 동일 너비, 12dp 간격이다. 글자를 자르거나 글꼴 확대를 제한하지 않고 줄바꿈에 따라 높이가 늘어난다.
- 내부 여백만 25% 줄였으므로 버튼 전체 높이를 25% 줄인 것은 아니다. 기본 글꼴에서 안쪽 표면은 채움 42dp/테두리 44dp, 바깥 조작 영역은 최소 48dp다. 기기 지정 확인·해제·취소에도 같은 여백을 적용했다. 다른 화면의 공용 버튼은 변경하지 않았다.

10/28 종료 시점에는 기능 브랜치에 미커밋 상태였으며 커밋·푸시·배포를 수행하지 않았다. 화면 원본·기기 정보·비밀값을 Git/Notion에 올리지 않았다.

## 2026-10-29 실기기 재검증 및 인계

사용자의 USB 연결 및 테스트 승인 후 기존 로컬 합성 계정용 HTTPS 서버와 최신 Metro 번들을 연결했다. 실제 금융 정보나 실제 계정 비밀번호는 사용하지 않았다. 오늘 제품 코드는 추가 수정하지 않고 위 변경을 검증했다.

### 실기기 결과

- 연결된 Android 휴대폰의 세로 화면에서 ‘알림 설정’ 제목, 변경된 본문, 왼쪽 ‘자세히 알아보기’/오른쪽 ‘알림 허용’ 2열을 확인했다. 두 열의 너비는 같고 간격은 12dp다.
- 기기의 기존 글자 배율 0.8과 확대 배율 1.3에서 본문과 두 버튼의 글자가 잘리지 않았다. 두 버튼의 조작 높이는 48dp로 유지됐다. 기기 지정 해제 버튼의 압축된 표면도 확인했다. 모든 지정 확인/취소 상태의 시각 검증까지 확장한 것은 아니다.
- 안내 팝업의 마지막 문단까지 스크롤, 고정 닫기 버튼, Android 뒤로가기로 설정 화면 복귀를 확인했다.
- 기존 동의 상태의 ‘알림 허용’ 팝업을 열고 취소한 전후 서버 동의/수집 기기 지정 버전이 바뀌지 않았다. OS 허용 스위치를 자동 조작하지 않았다.
- 최종 화면은 알림 허용 및 현재 기기 지정 상태였다. 이 상태는 임의로 철회하지 않았고, 글자 배율은 원래 값 0.8로 복원했다. 실제 알림 읽기·분석·자동 저장은 여전히 미구현이다.
- 시험 중 화면 상태가 바뀌어 일부 시도는 중단하고 현재 화면을 다시 확인했다. 완료 판단은 이후 재확인한 결과만 기준으로 했다. 글자 크기 변경으로 앱 화면이 다시 시작되는 경우에도 설정을 다시 열어 확인했다.
- TalkBack, 가로 화면, 다른 제조사/태블릿, 모든 글자 배율은 미검증이다. 이번 확인을 전체 접근성 감사나 모든 Android 기기 호환 보증으로 해석하지 않는다.
